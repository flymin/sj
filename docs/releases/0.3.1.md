# sj 0.3.1

Read a job's stdout inside the fullscreen queue, with lazy loading, search, and familiar pager controls.

## Stdout in task details

- Press Enter on a task, then Tab or Shift+Tab to select **Stdout**. Logs load only on the first visit, open at the tail, and reuse their snapshot when revisited.
- Browse the entire file through bounded read windows, without a file-size or line-count limit. Unwrapped views expand their cache to keep long records visible across the viewport and refill after resizing.
- See `Line current/total` alongside the percentage. The current line is the logical log line at the top of the viewport; wrapping does not increase the count. Totals are counted in the background with bounded index memory.
- Press `r` to reopen appended or rotated output. Queue refreshes do not read stdout. Leaving the tab or closing details cancels pending work; failed reloads retain the readable snapshot.

## Search and pager controls

- Raw and Stdout start without line wrapping. Use Left/Right, or Ctrl+Left/Right for a horizontal page; `w` toggles wrapping.
- In Stdout, `/` starts a literal, case-sensitive search. Enter confirms, `n` finds the next match, and `N` finds the previous one. Visible matches are highlighted, including across wrapped rows.
- Searches stop at file boundaries by default. Set `[tui].search_wrap = true` to enable looping. Esc cancels a search draft or active scan.
- Use `g`/`G` for file start/end, `j`/`k` and `h`/`l` for movement, `f`/`b` for a full page, and `d`/`u` for a half page. Ctrl+F/B/D/U also work.

## Compatibility and reliability

- Stdout uses the same path resolution as `sj out`; step details open their parent allocation's sbatch output. ANSI styling is removed and carriage-return progress updates become separate lines.
- Fixed cancellation on stalled filesystems using a bounded reader policy, preserved ANSI parser state across read windows, restricted match highlighting to visible content, and corrected controller fallback for incomplete accounting paths and unrelated stream patterns.
- Fixed a race in the TUI test counter's updates, and added regression coverage for lazy loading, cancellation, large files, long records, wrapping, line counters, and search boundaries.
- Updated English and Chinese READMEs and shortcut help. Configuration schema remains version 1; existing files are preserved.

Static Linux binaries are available for **x86_64** and **aarch64**, with `SHA256SUMS` for verification.
