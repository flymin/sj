# sj 0.2.1

Show the entries you need inside each column, with shorter help at every level.

## Display-only column entry filters

Configure any resource or key/value column with glob-based key selection:

```toml
[views.queue.columns.tres-alloc.entries]
include = ["cpu", "mem", "gres/*"]
```

- Optional `include` and `exclude` lists select complete keys; exclusion wins.
- Literal `separator` and `key_separator` settings support other field formats.
- Settings inherit through global columns, views, and terminal-width rules.
- Selection happens before width allocation, including stacked output and watch refreshes. Job filters continue to see the complete raw values.
- Disabled by default. Existing configuration files are preserved; both READMEs and the generated configuration provide examples.

## Concise help

- Reorganized help groups options by task and keeps a few focused examples.
- `-h`, `--help`, and `sj help` share the same concise help; detailed reference material lives in the README.
- `config path`, `config views`, and `config check` have their own help, also available through commands such as `sj help config check`.

## Packaging and installation

- Added the MIT License, including its copyright notice, to the repository and binary archives.
- Build installation now defaults to `$HOME/.local/bin`; `SJ_INSTALL_DIR` still selects another directory.
- Updated English and Chinese installation examples to use a portable checkout and installation path.

Configuration schema remains version 1. Download the static Linux archive for `x86_64` or `aarch64`, and verify it with `SHA256SUMS` before installation.
