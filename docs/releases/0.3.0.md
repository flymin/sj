# sj 0.3.0

Browse the queue in a fullscreen terminal interface, then inspect a task without leaving the view.

## Fullscreen queue

```bash
sj --tui --me
sj q --tui --me -i 2
sj q --tui --steps
```

- Navigate jobs and steps with arrow keys, PageUp/PageDown, and Home/End. Horizontal scrolling keeps every column referenced by the selected view accessible.
- Press Enter for an Overview / Raw popup with the queue snapshot and controller details for the exact job or step. Raw preserves complete field values, including entries hidden in the table.
- See the refresh interval, last successful update, retained/fetched row counts, and state totals. Pause with Space, refresh with `r`, and adjust the interval with `+` / `-`.
- Keep the selected task across refreshes and window resizing. Failed queries retain the last successful snapshot and display a stale status.
- Use `?` or F1 for shortcuts; `q` / Esc closes a popup or exits the queue. Ctrl+C exits from any screen and restores terminal settings.

## Layout and configuration

- Spare screen width expands columns toward their natural widths in `grow_priority` order, bounded by `max_width`. Long task names can use the available width.
- The active responsive rule determines the leading column order; other columns referenced by the view's base/rule orders remain reachable by scrolling.
- Set `[tui].refresh_seconds` (default 5) and customize title, selection, border, key, error, and muted styles through `[theme.tui]`. CLI `-i` overrides the configured interval; runtime adjustments are not saved.
- Reuse existing views, boolean job filters, display-only entry filters, and state colors. Color-free output retains selection markers and readable status text.

## Reliability and documentation

- Slurm queries run asynchronously with bounded timeouts and cancellation. Startup interrupts and query cancellation clean up command processes without waiting indefinitely for detached pipe owners.
- Controller summaries recognize canonical nested step fields, update stale snapshot aliases, and preserve memory units and per-CPU/per-node basis.
- Updated concise help, English and Chinese READMEs, configuration comments, and TUI examples.

Configuration schema remains version 1, and existing configuration files are preserved. Plain queue output and watch-style `-i` keep their existing behavior. TUI requires terminal stdin/stdout and cannot be combined with native output formats, `--list-fields`, `--width`, or `--noheader`.

Download the static Linux archive for `x86_64` or `aarch64`, and verify it with `SHA256SUMS` before installation.
