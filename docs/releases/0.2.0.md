# sj 0.2.0

Build your own Slurm queue view, then keep only the jobs you care about.

## Configurable views

- Named TOML views with reusable columns, alignment, width limits, truncation, and shrink/hide/grow priorities.
- Responsive rules that adapt layouts and themes to terminal width.
- Native Slurm fields for both jobs and steps, including fields beyond the default queue columns.
- First-use configuration at `$XDG_CONFIG_HOME/sj/config.toml`, falling back to `$HOME/.config/sj/config.toml`; existing files are preserved.
- `--config`, `--view`, and `sj config path|views|check` for selection and validation.
- Wrapped job records when mandatory columns cannot fit on a single line.

## Boolean field filters

```bash
sj --me --filter '(Name glob "train-*" or Name =~ "^eval") and not (Name glob "*test*")'
sj q --steps --filter 'StepName glob "worker-*"'
```

- Regex, Unix shell patterns, exact string comparisons, and `and`/`or`/`not` with parentheses.
- Filters use complete native values and can reference fields absent from the view.
- View defaults and repeated `--filter` conditions combine with AND; `--no-view-filter` skips the view default.

## Terminal experience

- `-i` shows the refresh interval and last successful update time, recalculating layout after resizes.
- Configurable headers, rows, state colors, column styles, and watch status; `--color auto|always|never` and `NO_COLOR` support.
- Consistent help and bilingual documentation for configuration, filtering, and existing log/script/shell helpers.

## Upgrading

Install the archive matching `uname -m`: Linux `x86_64` or `aarch64`. Both executables are statically linked. Verify the downloaded archive with `SHA256SUMS` before installation.

The default view retains remaining time, elapsed time, and wide-screen partition/node columns. `--steps` now uses an adaptive step view. Explicit native formats such as JSON/YAML or `-o`/`-O` still bypass adaptive output and cannot be combined with field filters or `--view`.

Configuration schema remains version 1. Configuration is read at startup; restart sj after editing it.

Compatibility and validation fixes preserve native option values such as job names beginning with `--`, compact `PendingTime` integer seconds correctly, and validate default views against the appropriate job/step catalog. Slurm versions without `--helpFormat` use a compatibility field catalog shared by upstream 22.05 and 23.11; version-specific fields remain available through explicit native output.
